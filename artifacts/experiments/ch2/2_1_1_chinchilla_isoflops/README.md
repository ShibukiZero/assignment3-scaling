# Chapter 2 Archived Outputs

This directory contains the confirmed archived outputs for the synthetic
`chinchilla_isoflops` analysis from Assignment 3.

Files:

- `model_size_scaling_law.png`: log-log fit of `N_opt(C)`
- `dataset_size_scaling_law.png`: log-log fit of `D_opt(C)`
- `optimal_points.csv`: selected minimum-loss point for each compute budget
- `fit_summary.json`: fitted coefficients, `R^2`, and predictions for `1e23` and `1e24` FLOPs

These files were promoted from the exploratory run under
`runs/chinchilla_isoflops_run1/` after review.

Naming note:

- `experiments/ch2/2_1_1_chinchilla_isoflops/` follows the chapter-based archival convention for Assignment 3 outputs.
